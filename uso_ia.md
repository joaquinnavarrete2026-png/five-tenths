# Registro de Uso de Inteligencia Artificial

Durante el desarrollo de esta actividad colaborativa, se utilizó asistencia de Inteligencia Artificial para:
* Configuración inicial del entorno de estilos y resolución de compatibilidad con PostCSS/Tailwind.
* Estructuración del componente de consumo asíncrono (`fetch`) para la API de Open-Meteo utilizando TypeScript.
* Diseño y refinamiento de la interfaz de usuario en formato de tarjeta moderna y centrada.
