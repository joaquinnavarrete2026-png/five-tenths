# Panel Meteorológico - La Araucanía

Proyecto colaborativo de desarrollo Front-End enfocado en la creación de un panel en tiempo real utilizando la API de Open-Meteo para las comunas de la Región de La Araucanía.

## Tecnologías Utilizadas
* React (TypeScript)
* Vite
* Tailwind CSS
* Open-Meteo API

## Instrucciones de Instalación y Ejecución
1. Clona el repositorio o descarga el código fuente.
2. Ejecuta `npm install` para instalar las dependencias.
3. Ejecuta `npm run dev` para iniciar el servidor de desarrollo local.
